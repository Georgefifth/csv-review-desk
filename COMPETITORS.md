# Competitive review

Reviewed 2026-10-13. **Observed** means an actual public UI task in this research session or the immediately preceding research in the same conversation. **Documented** means the vendor/repository says so. Claims about human speed, adoption and willingness to pay remain untested.

## Comparison

| Product | Completeness and strengths | Workflow and design | Price and limits | Evidence and remaining uncertainty |
|---|---|---|---|---|
| [ReadyCSV](https://www.readycsv.com/) | HubSpot-specific checks, inline repairs, local rules, project files, import and spreadsheet-safe exports | Guided checkpoints plus a detailed workspace; more complete domain guidance than ours | [Free Local; Pro $49 once; Agency $149/year](https://www.readycsv.com/pricing). Public UI lists 10 MB CSVs | Observed: loaded its 10-record sample, selected HubSpot, edited one invalid email, reran analysis: critical findings fell 3→2. It explicitly flags stale analysis. Project resume is documented/UI-visible, not independently tested there. No large-file timing test |
| [CSV Workbench](https://csvworkbench.com/documentation.html) | Frictionless schemas, multiple types, local editing, background validation, offline support, SQL | Folder/file/schema workflow; supports larger data work than our bounded importer | Official docs describe editable tables through 50 MB and require latest desktop Chrome/Edge. [Browser client is free](https://csvworkbench.com/); comma-only format | Documentation reviewed; no completed task in its editor. Auto-save writes directly to the selected local file. Our copy-based exports are a different tradeoff, not proof of superiority |
| [Essential Designs Import Mapper](https://www.essentialdesigns.net/tools/data-import-mapper) | Mapping, required/unique/type/enum rules, clean/rejected CSVs, reports, generated validation code | Direct mapping table; approachable rule configuration. Tested interface directs rejected records to external repair | Public free tool; also advertises XLSX input. No independently measured maximum file size | Observed: its 4-record example with ID uniqueness and email checks produced 2 ready/2 needing attention. No inline cell editor appeared in the tested interface. Not proof that every mode lacks editing |
| [csv.repair](https://www.csv.repair/) | Broad editor, undo/redo, repair templates, search, SQL, merge/split. [Repository](https://github.com/hsr88/csv-repair) documents workers and virtual scrolling | Public import preview exposes delimiter/encoding, then a dense multi-tool editor; keyboard shortcuts are prominent | Free. Documentation claims millions of rows; not stress-tested | Observed this turn: loaded our 2-record/7-column synthetic file, inspected preview, imported into editor; quoted text, IDs and phones stayed intact. Import preview briefly showed “Checking”; automation elapsed time is not user latency. Live UI offered default analytics with opt-out, while repo text says no tracking; privacy claims were not independently audited |
| [CSVbox](https://csvbox.io/pricing/) | Inline errors, correction, embeddable imports and [no-code import links](https://help.csvbox.io/advanced-installation/import-links); much broader integration capability | File→map→validate→submit. Appropriate when a SaaS needs an embedded importer | Pricing shown with annual billing: Sandbox $0 (5 rows/import), Startup $16/month (10k rows/import), Pro $39/month (50k). Terms may change | Official [inline-repair guide](https://blog.csvbox.io/fix-errors-inline/) and pricing reviewed. No account created and no live import completed. Integration benefits do not apply to every standalone local task |

These products offer stronger domain rules, larger-file workflows, more input formats, richer schema support, keyboard operation, or resume capabilities. Their larger feature sets are valuable for their intended users. We did not add SQL, charts, database ingestion or AI to match a checklist.

## User evidence and existing-solution preflight

- [Actual Budget issue #7796](https://github.com/actualbudget/actual/issues/7796) reports delimiter/skip/header changes resetting previously selected mappings and date/amount options. This is a concrete recovery/setup complaint; it does not establish demand for our product.
- [Excel users discussing CSV leading zeros and dates](https://www.reddit.com/r/excel/comments/ftq086/) illustrate source-string risks. [Microsoft provides automatic-conversion controls](https://support.microsoft.com/en-us/excel/keeping-leading-zeros-and-large-numbers); preservation alone is not an unmet market.
- [ImportCSV](https://github.com/importcsv/importcsv) and its [standalone component docs](https://github.com/importcsv/importcsv/blob/main/frontend/docs/importer-api.md) already provide frontend-only validation and mapping. Replacing our small working static app with a React component would add migration cost without resolving the identified state/recovery defects. Reconsider it if an embedded importer becomes the goal.
- Founder promotion posts were reviewed but excluded as independent customer adoption evidence. We found no credible comparative user-speed data across these five products.

## Chosen competitive scope

Serve a bounded local handoff: “check this CSV against my chosen rules, resolve each error, preserve strings and originals, and export an audited copy.” The update aims to reduce irrelevant scanning and protect work. Those improvements are tested against our baseline. They do not establish an exclusive feature, a market moat, or superiority over all alternatives.
